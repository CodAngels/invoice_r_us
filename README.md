# Octto landing page

One-page site for **Octto**, an accounts receivable teammate. Aimed at outsourced
accounting and AR firms, to recruit design partners.

**Live:** https://codangels.github.io/invoice_r_us/

## Files

```
index.html                    the whole page, no build step or dependencies
assets/Octto.png            logo, background flood-filled to transparent
assets/og-card.png            1200x630 link preview card
assets/favicon.ico            multi-res (16/32/48/64)
assets/favicon-32.png
assets/icon-192.png
assets/icon-512.png
assets/apple-touch-icon.png   180x180, composited on white for iOS
.nojekyll                     serve files as-is, skip Jekyll
```

Everything is inline: one HTML file with a `<style>` block. No CSS framework, no JS,
no webfonts. Open `index.html` in a browser to preview locally.

## Deploying

GitHub Pages serves from the default branch root:

1. **Settings → Pages → Build and deployment**
2. Source: *Deploy from a branch*
3. Branch: `main`, folder: `/ (root)` → **Save**

First build takes a minute or two. All asset paths are relative, so the site works from
the `/invoice_r_us/` subpath without changes.

## Editing notes

- **Palette** lives in the `:root` custom properties at the top of the `<style>` block.
  The page is deliberately single-theme (white paper, navy ink), so there are no dark-mode
  overrides, so it looks identical on every prospect's screen regardless of their OS
  setting. Red `--crit` is reserved for overdue amounts and blocked cases.
- **Contact** is a `mailto:` in two places: the two CTA buttons and the footer. Search
  for `onyandoroy@gmail.com` to swap in a domain address or a booking link.
- **Every sample figure is labelled illustrative**: the case queue, the case card, and
  the month-end stats. These are examples of the intended output, not customer results.
  Keep the labels if you change the numbers.
- **`og-card.png`** is regenerated by `tools/build_assets.py` if the logo changes; it
  needs Pillow and reads fonts from `C:\Windows\Fonts`.
